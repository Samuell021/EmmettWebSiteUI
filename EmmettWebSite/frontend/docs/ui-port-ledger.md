# دفترچهٔ پورت «UI» → فرانت‌اند Next.js

این سند، «دفتر کل» پورت ۱:۱ بستهٔ طراحی `UI/` (خروجی Figma Make) به فرانت‌اند Next.js
(``EmmettWebSite/frontend/``) است: چه چیزی منتقل شده، چه چیزی عمداً منتقل نشده و چرا، و
چه چیزهایی برای فازهای بعد باز مانده است.

## قواعد ثابت این پورت

1. **بک‌اند (Django/DRF) صفر تغییر** — نه مدل، نه ویو، نه مهاجرت. هر جایی که بک‌اند
   کمبود داشته باشد، مسئله در سمت فرانت حل می‌شود.
2. **ظاهر پورت‌شده مو‌به‌مو همان UI است** — کلاس‌ها، هگزها، فاصله‌ها و موشن‌ها بدون
   تغییر؛ فقط سه تبدیل مکانیکی مجاز است: ``to=`` → ``href=``، افزودن ``"use client"``،
   و معادل‌های ناوبری/locale (``react-router`` → ``@/i18n/navigation``).
3. **دو زبانه (fa/en) و کاملاً داینامیک** — محتوای هر بخش از API بک‌اند می‌آید
   (``Accept-Language``)، متن هاردکد UI فقط fallback است.
4. **آزمون پذیرش بصری** — پس از هر فاز، مقایسهٔ خروجی build با حالت قبل؛ حذف/تغییر
   هر قاعدهٔ CSS موجود ممنوع است.

### ب) توکن‌ها و «چرا scoped؟»

در فاز ۱ مقادیر UI زیر کلاس ``.ui-theme`` تعریف شده‌اند (نه در ``:root``)، به دو دلیل:

1. باید **هیچ‌چیز از UI جا نیفتد**: همهٔ ۴۸ توکن با همان نام‌ها/مقادیر + کل لایهٔ base،
   زیرمجموعهٔ ``.dark`` (که مقادیرش با ``:root`` مو‌به‌مو یکی است — با ابزار بررسی شد:
   ۳۴ کلید مشترک، صفر تفاوت)، و قاعده‌های ``h1..h4/label/button/input``.
2. باید **مسیرهای فعلی هیچ تغییر بصری نگیرند**: ۱۸ مسیر فعال هنوز با دیزاین‌سیستم
   قبلی (ADR-0017) کار می‌کنند و بازطراحی‌شان فاز ۷ است.

سازوکار فنی: نگاشت‌های ``@theme inline`` در ``globals.css`` هر کلاس معنایی را به
متغیر زنده تبدیل کرده‌اند (``.bg-background → background-color: var(--background)``،
``.rounded-lg → border-radius: var(--radius-value-lg)``، ``.border-border → border-color:
var(--border)``). پس هر عنصر داخل ``.ui-theme`` خودکار مقدار درست UI را می‌گیرد —
**بدون تغییر حتی یک کلاس در کد پورت‌شده**. این ادعا در خروجی build راستی‌آزمایی شد.

نکتهٔ حیاتی گردی‌ها: UI برای ``rounded-md`` و ``rounded-lg`` مقادیر ۶px و ۸px دارد اما
دیزاین‌سیستم فعلی ۸px و ۱۶px؛ به همین دلیل ``--radius-value-sm/md/lg`` داخل `.ui-theme`
بازتعریف شد تا ``rounded-md``/``rounded-lg`` در ناحیهٔ پورت مو‌به‌مو مثل UI شوند.

## موارد باز (برای فازهای بعد)

- **بریک‌پوینت‌ها:** UI از مقیاس پیش‌فرض Tailwind استفاده می‌کند (sm=640px…)، اما فرانت
  فعلی مقیاس برند دارد (sm=768px، md=1024px، lg=1280px، xl=1440px). این مورد
  **قابل scoped شدن نیست** (media queryها در زمان build ثابت می‌شوند) و پیش‌نیاز فاز ۲
  است؛ تصمیم آن باید پیش از پورت Home گرفته شود.
- **حالت روشن/تیره:** UI تک‌حالت تیره است؛ فرانت فعلی دکمهٔ تغییر تم دارد (next-themes).
  تعیین تکلیف برای فاز ۷.
- **پورتال‌ها:** محتوایی که با React Portal بیرون از درخت `.ui-theme` رندر شود، توکن‌های
  scoped را نمی‌گیرد (فاز ۲/۴ به آن توجه شود).
- **focus-visible:** قاعدهٔ سراسری فعلی فرانت داخل ناحیهٔ پورت هم اعمال می‌شود؛ در فاز ۲
  رفتار نهایی فوکوس با UI مقایسه و در صورت نیاز هم‌ارز می‌شود.
